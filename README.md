# Практическая работа 2, вариант 22. Этап 3

Граф зависимостей и рекурсивный DFS.

Python 3.9+, только стандартная библиотека. Сборка не требуется.
Команды выполняются из папки с этим README.

## Настройки

| Параметр | Назначение |
| --- | --- |
| `--package` | Имя пакета, обязательно |
| `--version` | Точная версия пакета, обязательно |
| `--repo` | URL каталога репозитория с архитектурой или путь к JSON, обязательно |
| `--test-repo` | Использовать тестовый JSON; иначе читается APKINDEX |

В тестовом режиме имена пакетов записываются большими латинскими буквами.
URL указывается до каталога архитектуры, например:
`https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64`.
Имя `APKINDEX.tar.gz` программа добавляет сама.

## Запуск

```sh
sh run.sh --test-repo --repo fixtures/chain.json \
  --package A --version 1.0
python3 -m unittest discover -s tests -v
```

Результат для цепочки:

```text
A: B
B: C
C:
```

## Тестовый репозиторий

```json
{"A": {"1.0": ["B"]}, "B": {"1.0": []}}
```

Ключи — имена пакетов, вложенные ключи — версии, значения — списки зависимостей.
Используются три примера:

- `fixtures/chain.json`: цепочка A -> B -> C и отдельный D.
- `fixtures/diamond.json`: общий D у B и C, две версии A.
- `fixtures/cycle.json`: цикл A -> B -> C -> A, петля и отдельный пакет.

Для демонстрации разных случаев меняйте имя файла и пакета в команде запуска.

## Функции

| Функция или метод | Назначение |
| --- | --- |
| `main.read_args` | Читает параметры и обрабатывает ошибки ввода |
| `main.main` | Выполняет текущий этап |
| `repository.parse_index` | Читает поля P, V, D и p |
| `repository.load_apk` | Скачивает и читает APKINDEX в памяти |
| `Repository.__init__` | Сохраняет записи пакетов в словаре |
| `Repository.get` | Выбирает запись пакета по имени и версии |
| `repository.dependency_name` | Отделяет имя от ограничения версии |
| `repository.load_test` | Читает тестовый JSON |
| `Repository.resolve` | Находит пакет по имени или предоставляемой библиотеке |
| `Repository.dependencies` | Возвращает имена зависимостей без конфликтов и повторов |
| `graph.dfs` | Рекурсивно обходит граф; вложенная visit посещает вершину |
| `graph.dependency_graph` | Строит прямой граф; get_neighbors читает соседей |

Ошибки параметров завершают программу с кодом 2, ошибки загрузки или поиска — с кодом 1.
Успешный запуск возвращает 0. Дополнительных проверок структуры JSON нет.
Для корня выбирается точная версия. Для остальных пакетов используется первая
подходящая запись индекса. Полный решатель версионных ограничений не реализуется.

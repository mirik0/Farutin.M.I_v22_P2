# Граф зависимостей APK — вариант 22

Консольная программа на Python для анализа зависимостей пакетов Alpine Linux.
Метаданные читаются из APKINDEX или тестового JSON.
Граф строится рекурсивным DFS и выводится в формате PlantUML.

## Запуск и настройки

Нужен Python 3.9 или новее. Дополнительные библиотеки и сборка не нужны.
Команды выполняются из папки проекта:

```sh
sh run.sh --test-repo --repo fixtures/diamond.json --package A --version 1.0
python3 -m src.main --test-repo --repo fixtures/chain.json --package A --version 1.0
```

- `--package` — имя пакета, обязательный параметр.
- `--version` — точная версия пакета, обязательный параметр.
- `--repo` — URL репозитория или путь к тестовому JSON, обязательный параметр.
- `--test-repo` — использовать тестовый JSON вместо настоящего репозитория.
- `--help` — справка по запуску.

Для настоящего репозитория нужен интернет. Пример URL:
`https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64`.
Имя архива `APKINDEX.tar.gz` программа добавляет сама.

## Тестовый репозиторий

Имена пакетов записываются большими латинскими буквами.
У каждого пакета указаны версии и списки зависимостей:

```json
{"A": {"1.0": ["B"]}, "B": {"1.0": []}}
```

В `fixtures/` есть три примера: `chain.json` — цепочка,
`diamond.json` — общая зависимость и две версии A,
`cycle.json` — цикл, петля и отдельный пакет.

## Результат

Программа выводит описание графа между `@startuml` и `@enduml`.
Циклические связи сохраняются, повторный обход вершин прекращается.
Версия исходного пакета выбирается точно; для остальных берется первая запись индекса.

В `examples/` лежат графы для busybox, zlib и xz и соответствующий вывод `apk dot`.
Сравнение результатов описано в [docs/COMPARISON.md](docs/COMPARISON.md).

## Код

- `src/main.py`: `read_args` читает настройки, `main` запускает программу.
- `src/repository.py`: `parse_index` разбирает APKINDEX, `load_apk` загружает архив,
  `load_test` читает JSON, `dependency_name` отделяет имя от ограничения версии.
- `Repository.__init__` сохраняет записи; `get` находит пакет;
  `resolve` находит поставщика библиотеки; `dependencies` получает имена зависимостей.
- `src/graph.py`: `dfs` выполняет обход, вложенная `visit` посещает вершину;
  `dependency_graph` строит граф, вложенная `get_neighbors` получает соседей.
- `src/plantuml.py`: `to_plantuml` формирует описание вершин и связей.

Подробный разбор решения: [docs/OVERVIEW.md](docs/OVERVIEW.md).

## Тестирование

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют параметры, чтение APKINDEX, версии, DFS, циклы
и сравнение трех графов с сохраненным выводом `apk dot`.
Скрипт `run.sh` предназначен для macOS и Linux.
